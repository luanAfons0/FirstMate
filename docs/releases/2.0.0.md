# FirstMate 2.0.0

FirstMate is now an **App**: one Windows program that holds the Host, the Tray and the window. The npm package is the command line only, and installs the App for you.

## What changes

- **Install the App** with `npx @luan-afonso/firstmate desktop`, from Windows or from inside WSL. It downloads the installer of its own version, checks its SHA-256, and installs it for you alone, with no administrator. The App updates itself.
- **Plugins live in Places.** The `windows` Place is this machine. A `wsl` Place is one WSL distribution, where your 1.x Plugins already are: they keep running there, unchanged, through `wsl.exe`. Each Plugin moves to `windows` in a release of its own.
- **The window** gives each Plugin Page a view of its own, which stays loaded until you quit, so switching away loses nothing. The strip's switcher lists every Plugin in the Plugin Order. Closing the window hides it; Quit, in the Tray, ends the App.
- **The Tray, Notices and Shortcuts** are the App's own: the Tray wears the stopped mark while a Plugin is Stopped, a Notice is a Windows notification, and a Shortcut opens its Popup with no helper.
- **The Settings View** adds and removes a Place, moves each Place's Shelf, turns start at logon on and off, and shows the Shortcuts.
- **A Plugin Page may use the microphone or capture the screen** only after you allow it, once per Plugin. Every other permission is refused.
- **The Host's home** on Windows is `%APPDATA%\FirstMate`. `FIRSTMATE_HOME` still moves it.
- **Gone:** `firstmate start`, `firstmate service`, the systemd unit, the Windows logon task, the PowerShell helpers and the 1.x window. The App does all of their jobs.
- **New:** `firstmate place`, `firstmate import`, `firstmate logs [-f]`, and `--place` on `add`, `install` and `shelf`.
- **For Plugin authors:** on Windows the Host runs `mcp.cmd` or `mcp.exe` from your Plugin directory, and gives every Plugin Server `FIRSTMATE_NODE`, the Node to run a Node Plugin with. Your `mcp` file keeps working as it is in a `wsl` Place. See `docs/plugin-guide.md`.

## How to move from 1.x

1. Install the App: `npx @luan-afonso/firstmate desktop`.
2. Add the distribution your 1.x Host runs in as a Place, and import it:

   ```sh
   firstmate place add debian wsl Debian
   firstmate import debian
   ```

   Your Plugins, Grants, Shortcuts, Plugin Order and Shelf come across. Every Plugin stays where its directory already is. `import` asks before it turns the 1.x systemd service off, because the 1.x Host holds port 4747. Say yes.

   `firstmate setup` offers the same import when it finds a 1.x install.
3. If you used the 1.x Windows logon task, remove it with the `uninstall-logon-task.ps1` your 1.x install printed, or from Task Scheduler. Turn start at logon on in the App's Tray or its Settings View instead.
4. Read the Host's output with `firstmate logs -f`. It replaces `journalctl --user -u firstmate -f`.

## Known

- The betas are not signed. Windows Smart App Control blocks an unsigned program, so a PC with it on cannot run a beta.
