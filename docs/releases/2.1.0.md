# FirstMate 2.1.0

FirstMate is a local plugin host: one App, for Windows and Linux, that gives each of your own tools a process, a page and an address. This version adds the Mate, a chat with your own Agent, and lets every Official Plugin run on this machine, with no WSL.

## What changes

- **The Mate.** Ask your own Claude Code or Codex from the App or from a terminal. FirstMate holds no model key and calls no model of its own: the Agent runs on your own account, with its own login and plan ([ADR-0031](../adr/0031-the-app-holds-the-mate.md)).
  - In the App, open the Mate panel from the strip or with `Ctrl+Shift+K`, or type in the box above the Plugin list. Recents shows every Conversation, and opens one again.
  - From a terminal, `firstmate ask <question>` asks, and `firstmate ask --conversation <id>` continues a Conversation, one started here or in the App. `ask` needs no running Host.
  - The Settings View sets the Agent, the model, the effort, the Place and the program. They are kept under `mate` in `settings.json`.
  - A new Conversation first tells the Agent what FirstMate is, which Plugins you have, and what your `mate.md` says.
  - FirstMate approves no tool for the Agent: it may do what your own Agent settings allow. The Host's token never shows in an answer.
- **Every Official Plugin runs in a `local` Place.** `worklog`, `scheduler` and `nexus` start from `mcp.ts` on the Host's own Node, so on Windows they run in the `windows` Place, with no WSL. `setup` offers them every Place they can run in, and asks which when there are two or more.
- **Two new Official Plugins.** `research` reads the pages you list for a subject, and makes a Digest of them. `scribe` records a call in the FirstMate window, and makes its Minutes. Install them by name: `firstmate install research`, `firstmate install scribe`. `scribe` calls `worklog`, so `setup` offers it Grants.

## How to move a Plugin from a `wsl` Place to `windows`

FirstMate does not move a Plugin's data: the data is the Plugin's own ([ADR-0005](../adr/0005-plugins-own-their-data.md)). For each Plugin you want to move:

1. Copy its data out of its directory in the distribution, such as `worklog.db`.
2. Remove it, and install it again in the `windows` Place:

   ```sh
   firstmate remove worklog
   firstmate install worklog
   ```

3. Put its data back into the new directory, and give its Grants again with `firstmate grant`.

A Plugin you leave in its `wsl` Place keeps running there, as before.

## Known

- The App is still not signed. Windows may say the App is unknown; select **More info**, then **Run anyway**. See the [README](../../README.md#windows-says-the-app-is-unknown).
- `scribe` records no Call on native Linux, because the App gives a capture its sound on Windows only ([scribe#32](https://github.com/luanAfons0/scribe/issues/32)).
